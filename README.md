# Nauterm website

Official website for [Nauterm](https://github.com/korvect/nauterm), built with React, TypeScript, Vite, Tailwind CSS, and shadcn-style components.

## Development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

Pushes to `main` are deployed to GitHub Pages by `.github/workflows/deploy.yml`.
